# AGENTS.md

Personal Jekyll blog. Solo project, no Jira, no review process.

## Posts

- After writing or editing a post in `_posts/`, run the `review-post` skill on it before committing.

## Git

- Commit and push directly to `main`. Feature branches and pull requests are not used here.
- When asked to commit, commit right away with a message you write; approval of the message is not needed.
- Commit messages: a short lowercase summary with no ticket or branch prefix (e.g. `add post about archiving old posts`). Add a bullet body only for multi-file changes. This overrides the global commit-message skill for this repo.
